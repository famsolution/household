보험 영업 도구 모음 🧰

대면 미팅·미러링에서 바로 쓰는 도구들. 모두 단일 파일이라 다운로드해 로컬/미러링 기기에서 사용할 수 있어요.

🛡️
담보표 + 발표 모드
엑셀처럼 입력·시트 저장, 원하는 담보만 펼치기, 형광펜·말풍선·연결선 발표, 이미지 저장.
사용 가능
🪪
보장 요약 카드
담보표(.json)를 불러와 고객용 보장 요약 카드로 변환하고 이미지로 저장.
사용 가능
⚖️
상품 비교표
2~3개 상품을 나란히 놓고 담보·금액 차이를 자동 강조. 담보표(.json)를 상품 열로 불러오면 담보명 자동 정렬.
사용 가능
🧮
보장 합계 계산기
선택한 담보의 가입금액·보험료 합계를 즉시 계산하고 결과를 이미지로 저장.
