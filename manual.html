엑셀 담보표를 불러와 꾸미고, 고객 앞에서 강조·연결·합산까지. ← 도구 열기

  1. 📥 표 만들기에서 엑셀 불러오기(또는 예시)

1. 표 만들기 / 불러오기

상단 📥 표 만들기 버튼을 누르면 입력 창이 열립니다.

  • 📊 엑셀/CSV 파일 불러오기: .xlsx / .xls / .csv. 엑셀의 셀 병합·배경색·글자색·크기·굵기·정렬·열너비·행높이까지 그대로 가져옵니다. (색·글꼴은 .xlsx에 스타일 정보가 있을 때)
  • 붙여넣기: 엑셀에서 범위 복사(Ctrl+C) → 입력칸에 붙여넣기(Ctrl+V) → "붙여넣기로 표 만들기".
  • 빈 시트로 시작: 담보(행)·열 수를 정해 빈 표 생성.
  • 예시 데이터 불러오기: 처음이라면 샘플로 감 잡기.
표를 만들면 입력 창이 자동으로 닫히고, 아래 미리보기와 나머지 단계 버튼이 활성화됩니다.

직접 입력/수정: 셀을 클릭해 바로 타이핑. Tab=다음 칸, Enter=칸 안 줄바꿈(2줄), Shift+Enter=아래 칸.

2. 시트 저장 · 고객용 파일

💾 시트 저장·불러오기 버튼.

  • 이 시트 저장 / 불러오기: 여러 담보 세트를 이 브라우저에 보관(자동 임시저장 포함).
  • 📤 파일로 내보내기(.json) / 📥 파일 불러오기: 다른 PC·태블릿으로 옮길 때.
  • 💼 고객용(발표) 파일로 저장 (미리보기 아래 버튼): 선택·색·병합 + 발표 세팅(연결·고정·강조 등)까지 저장. 불러오면 "바로 발표 화면으로 열까요?"가 떠서 곧장 상담용으로 사용.

3. 담보 · 열 고르기

👁 담보·열 고르기 — 발표·이미지에 나올 항목만 추립니다.

  • 담보(행)·열의 체크를 끄면 숨겨집니다. 검색창으로 담보 찾기, 전체 펼치기/숨기기/반전.
  • ➕ 담보 추가 / ➕ 열 추가.

4. 디자인

🎨 디자인 — 표 전체 모양.

  • 글자 크기 · 가로/세로 여백 · 정렬 · 헤더 색 · 테두리 색.
  • 표 선 두께(슬라이더 또는 숫자, 0=투명) — 전체 표 선 굵기/숨김.
  • 표 라인: 가로선/세로선 전체 on·off.
  • 긴 글자 줄바꿈 허용.

5. 특약 골라 보기(대분류·중분류)

🧩 특약 골라보기 — 계층형(대분류>중분류>금액) 표에서 원하는 묶음만.

  • 대분류·중분류 행 지정: 엑셀 병합 헤더면 자동 추정(다르면 직접 선택, "행 목록 새로고침").
  • 대분류 묶음 칩: 체크 해제하면 그 특약(여러 열)이 통째로 접힘.
  • 대분류 + 중분류 선택 → "이 묶음만 보기": 예) 암통합치료비·기본형 → 4천·8천·1억 열만. "전체 보기"로 복원.
  • 빈 가로행 자동 숨기기: 표시 중인 열 기준으로 값이 빈 항목 행을 자동 숨김.
표에서 우클릭해도 됩니다 → 「이 열만 접기」 / 「이 묶음 전체 접기·보기」 / 「전체 펼치기」. 🎨 꾸미기에서 여러 열을 드래그 선택 후 우클릭하면 한꺼번에.

6. 셀 선택 · 꾸미기

미리보기 위 🎨 셀 선택·꾸미기를 켜면 화면 상단에 떠 있는 서식바가 나옵니다.

  • 선택: 셀 클릭 / 드래그(범위) / Shift(연속) / Ctrl(개별 추가).
  • 서식: 셀 배경색, 글자색, 크기, 굵게, 정렬.
  • 셀 병합 / 병합 해제(여러 셀 선택 후).
  • 테두리(변별): 선 위치(전체/가로/세로/위/아래/왼쪽/오른쪽) + 색 + 두께 슬라이더(0=투명). 특정 변만 두껍게 하거나 없애기.
  • 🙈 선택 열/행 감추기, 🗑 행/열 삭제.
  • 너비·높이: 열·행 경계를 마우스로 끌어 조절.
  • Ctrl+Z 실행취소 / Ctrl+Y 다시실행.
병합한 표에서 행/열을 삭제하면 겹치는 병합만 안전하게 풀리고, 나머지 셀의 테두리는 그대로 유지됩니다. 한 열만 감춰도 묶음 머리글은 남은 열 위로 자동 이동합니다.

7. 미리보기 확대 · 이미지 저장

  • 🔍 확대/축소(미리보기 위): 화면에서만 키워 보며 편집. 저장 이미지는 항상 100% 기준.
  • 💾 이미지로 저장(PNG) / 📎 이미지 복사: 체크 해제한 담보·열과 편집선은 빠진 깔끔한 표만 저장됩니다.

8. 발표 모드 — 강조 · 연결 · 합산

미리보기에서 🎬 발표 모드 시작. 도구는 화면 하단 바에 있습니다.

형광펜(강조)

  • 🖍 행 / 🖍 열 / 🖌 칸 모드를 고르고 표를 클릭·드래그 → 그 행/열/칸이 강조됩니다.
  • 왼쪽 ⋮·위쪽 ⋯ 핸들을 클릭/드래그해도 그 줄 전체가 강조됩니다.
  • 색 구분: 행=노랑, 열=하늘, 행+열 교차=로즈, 칸=노랑(하단 색칸에서 변경).

🔗 담보 연결

  • 연결 모드에서 연결할 칸을 순서대로 클릭합니다. 큰 항목뿐 아니라 세부항목 칸(예: 암수술 ↔ 다빈치로봇수술)도 콕 집어 연결.
  • 3개·4개 이상 연결 가능. 칸 사이를 곡선 + 순번(①②③)으로 잇고, 연결된 칸은 테두리로 표시. 다시 클릭하면 해제.

💬 합계 말풍선 / 💰 합산 보험금

  • 합계 말풍선: 그 열의 합계를 말풍선으로 표시(강조한 담보만 합산).
  • 합산 보험금: 금액열을 골라, 강조한 담보들의 금액을 덧셈식 + 총합으로 보여주고 해당 칸을 자동 강조.

그 외

  • 🔦 집중: 강조한 담보만 또렷하게(나머지 흐리게).
  • 🧹 지우기: 모든 효과 제거. ↶/↷ 또는 Ctrl+Z/Ctrl+Y로 단계 되돌리기.
  • 💾 화면 저장: 현재 발표 화면을 이미지로.

9. 행/열 고정 · 확대(줌)

  • 🧊 고정: 좌우/상하로 스크롤해도 머리글과 담보가 보이게 고정. 🧊 버튼 옆 "행 / 열" 숫자칸에 직접 입력해 고정할 위쪽 행 수·왼쪽 열 수를 정할 수 있습니다(🧊를 처음 누르면 추정값이 자동 입력되고, 숫자를 바꾸면 즉시 반영). 이 고정값도 파일에 저장됩니다.
  • 확대/축소: Ctrl+휠(또는 Ctrl+Alt+휠) → 발표 표만 커지고/작아집니다(도구바는 고정). 하단 크기 슬라이더로도 조절.

10. 발표 세팅 저장 · 재사용

발표 중 만든 연결·강조·고정·합산·크기·말풍선 세팅은 파일에 함께 저장됩니다.

  1. 발표 모드에서 원하는 대로 강조·연결·고정을 세팅.
  2. 편집으로 나와 💼 고객용(발표) 파일로 저장.
  3. 나중에 그 파일을 📥 파일 불러오기 → 발표 진입 시 세팅이 그대로 복원됩니다.
고객별로 다른 발표 파일을 미리 만들어 두면, 상담 때 불러와서 바로 보여줄 수 있습니다.
